# 数据结构设计

## 菜谱动作事件表

字段：event_id、recipe_id、recipe_version、machine_id、session_id、relative_time、absolute_time、action_type、target_channel、set_value、unit、duration、phase、source、is_manual、risk_tag。

## 状态轨迹表

字段：session_id、timestamp、set_power、control_power、actual_power、raw_temp、filtered_temp、display_temp、estimated_max_temp、energy_accumulated、pan_angle、pan_speed、motor_state、pump_state、temp_rise_rate、abnormal_flag。

## 设备上下文表

字段：machine_id、device_model、pot_type、pot_batch、pot_age、induction_model、line_coil_model、infrared_model、infrared_pollution_level、carbon_level、k_value、ab_value、last_clean_time、last_calibration_time、maintenance_history、health_score。

## 安全规则表

字段：rule_id、rule_name、rule_scope、condition、threshold_config、device_scope、risk_level、client_action、backend_action、owner、source、version、status、validation_status。

## 风险扫描结果表

字段：scan_id、recipe_id、machine_id、session_id、risk_score、risk_level、triggered_rules、high_risk_time_window、oil_to_food_interval、energy_before_food、review_status、suggested_action、created_time。
