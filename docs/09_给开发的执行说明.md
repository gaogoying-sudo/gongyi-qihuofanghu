# 给开发的执行说明

## 本轮只做什么

建设静态 HTML 工作台和历史 Markdown 文档沉淀，用于后续产品、开发、测试、口味、售后对齐。

## 不做什么

不做后端服务，不接真实数据库，不做账号权限，不做真实规则扫描，不做客户端真实下发。

## 本地部署

```bash
python3 -m http.server 5173
```

访问：

```text
http://localhost:5173
```

## VSCode 运行

1. 克隆仓库。
2. 用 VSCode 打开仓库目录。
3. 在终端执行 `python3 -m http.server 5173`。
4. 浏览器访问 `http://localhost:5173`。

也可以安装 VSCode Live Server 插件，直接打开 `index.html`。
