# 存量产品起火问题完整上下文接续包

## 背景

公司存量炒菜机器人产品出现锅内起火风险。该问题不是单一菜谱、单一客户或单一硬件失效，而是由菜谱结构、红外测温、设备健康、锅黑积碳、投油动作、投料时机、累计能量和客户端交互共同造成的系统性安全问题。

## 当前核心判断

真正的问题不是某道菜谱写了 15kW / 30s，而是存量机红外测温失真后，原本会被限温压住的同一条菜谱，会持续输出更多实际能量，导致真实锅温上冲并进入起火风险区。

## 当前方案方向

把菜谱从“表层功率 + 时间 + 温度限位”升级为“真实机芯控制功率曲线 + 实际输出功率曲线 + 能量戳 + 温度戳 + 异常兜底”。

## 主风险链

热锅 / 润锅到高温 → 高功率空烧 → 投油 → 投油后继续加热 → 延迟投主料 → 锅黑 / 焦渣形成局部热斑 → 投含水主料 → 水汽激发油烟 → 闪燃 / 爆燃。

## 当前推进原则

先不追求完整 AI 模型，先用专家规则 + 程序扫描 + 起火案例验证，把油、高温、空烧、投主料延迟、锅黑这条主风险链筛出来。
