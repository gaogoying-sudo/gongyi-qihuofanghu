# 应用工艺方案

## 工艺阶段

S0 初始化  
S1 热锅  
S2 润锅  
S3 投油  
S4 爆香 / 前处理  
S5 投主料  
S6 主炒  
S7 收汁 / 出锅  
S8 洗锅 / 复位  

## 核心策略

### 热锅 / 润锅前置安全控制

热锅目标温度分级，超过阈值进入风险判断。

### 投油后强约束

投油后进入高风险时间窗，必须判断投油后功率、持续时间、主料延迟和锅黑状态。

### 第一主料前累计能量限制

真正危险的不是单点温度，而是第一主料进入前锅和油已经累积了多少能量。

公式：

```text
E = Σ(P_i × Δt_i)
```

### 能量复刻

复刻对象是机芯收到的控制功率曲线，实际输出功率曲线用于校验。

### 锅黑风险上调

高温 + 油 + 锅黑，应提高风险等级。锅黑严重时，禁止运行高温投油类菜谱。
