# 问题归类与风险归类

## 问题归类

### 1. 菜谱结构问题

现有菜谱记录的是表层动作，缺少真实执行曲线、温度戳、能量戳、设备健康上下文和安全规则校验。

### 2. 测温问题

红外存在油膜污染、测点不是最高温、传感器老化、转锅方向滞后、温度跳变等问题。

### 3. 能量失控问题

同一条菜谱在录制时和存量机执行时，真实能量输出不同。测温偏低后，系统可能继续补功率，导致锅内真实能量累积超过原始安全边界。

### 4. 动作链问题

起火不是单点温度事件，而是高温、油、锅黑、空烧、投料延迟和累计能量共同触发。

## 风险等级

- L0 正常：不提示。
- L1 观察：后台记录。
- L2 提醒：弱提醒。
- L3 强提醒：弹窗确认。
- L4 限制：降功率或限制执行。
- L5 禁止 / 锁定：禁止执行或要求维保审批。

## 高优先级风险链

热锅 / 润锅到高温 → 高功率空烧 → 投油 → 投油后继续加热 → 延迟投主料 → 锅黑 / 焦渣形成局部热斑 → 投含水主料 → 闪燃 / 爆燃。
