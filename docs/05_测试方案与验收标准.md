# 测试方案与验收标准

## 测试任务

T1：日志与时间轴对齐测试  
T2：功率曲线采集测试  
T3：106℃ 起点策略验证  
T4：投油 / 投主料风险链测试  
T5：锅黑 / 积碳专项测试  
T6：危险菜谱规则筛选测试  
T7：客户端安全策略灰度测试  
T8：换锅 / 换机芯 / 换红外后基准失效测试  

## 测试环境要求

至少覆盖新机、旧机、红外污染样机、锅黑样机、不同锅型、不同机芯。

## 设备初始化要求

每次测试前记录机器型号、SN、锅型、锅黑等级、红外状态、机芯版本、线盘版本、软件版本、策略版本、环境温度、锅初始温度。

## 验收重点

已知起火案例必须被规则命中；高风险规则必须可解释；客户端策略必须可灰度和可回滚。
