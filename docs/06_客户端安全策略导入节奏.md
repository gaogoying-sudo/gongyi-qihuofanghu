# 客户端安全策略导入节奏

## 原则

后台先识别，内部先复核，高风险先干预，低风险先观察，客户侧分级灰度，极高风险必须强拦截。

## 节奏

1. 静默扫描：后台跑规则，不弹窗、不改菜谱。
2. 内部复核：产品、口味、测试、售后复核 L4 / L5 菜谱。
3. 灰度提醒：少量客户打开提醒，先提醒不拦截。
4. 强策略导入：对极高风险菜谱启用强提醒、降功率、停机或锁定。
5. 规则常态化：新菜谱保存前必须过规则，旧菜谱定期扫描。

## 客户端动作映射

- L0：无交互。
- L1：后台记录，不提示。
- L2：弱提醒，可自动消失。
- L3：弹窗确认。
- L4：自动降功率或缩短等待。
- L5：禁止执行，要求维保或审批。
